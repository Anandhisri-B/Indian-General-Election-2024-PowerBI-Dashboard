
 Indian General Election Results 2024 – Power BI Analysis

 Project Overview
An interactive, 6-page Business Intelligence dashboard built in **Microsoft Power BI** to analyze the **2024 Indian General Election (Lok Sabha)** results across all **543 constituencies**. The report breaks down alliance seat shares, party-wise performance, state demographics, and constituency-level voting trends.

Key Insights Highlighted
- **Total Constituencies Analyzed:** 543 (Voting: Apr 19 – Jun 1, 2024 | Results: Jun 4, 2024)
- **NDA Alliance:** 292 Seats (53.8% seat share across 14 parties, led by BJP with 240 seats)
- **I.N.D.I.A Alliance:** 234 Seats (43.1% seat share across 20 parties, led by INC with 99 seats)
- **Others:** 17 Seats (3.13% seat share)

 Dashboard Pages
1. **Landing Page:** Executive navigation hub.
2. **Overview Analysis:** High-level KPIs, parliament seat distribution hemicycle chart, alliance breakdown cards, and party-wise seat tables.
3. **State Demographic Analysis:** Regional and demographic breakdowns across Indian states and union territories.
4. **Political Landscape by State:** State-level party dominance and alliance performance comparisons.
5. **Constituency Analysis:** Granular drill-down into individual Lok Sabha constituencies, margins, and vote shares.
6. **Details Grid:** Searchable tabular view of complete election records for ad-hoc filtering.

 Repository Files
- `project2.pbix` – Main Power BI Desktop dashboard file
- `Party Alliance DAX.txt` – Custom DAX formulas and calculated measures used for alliance grouping and seat calculations
- `Problem Statement.pdf` – Project objectives and business requirements
- `constituencywise_details.csv`, `constituencywise_results.csv`, `partywise_results.csv`, `states.csv`, `statewise_results.csv` – Election datasets used for data modeling

 Tools & Technical Skills Used
- **Microsoft Power BI Desktop:** Custom hemicycle parliament visual, dynamic KPI cards, page navigation buttons, and interactive slicers.
- **DAX (Data Analysis Expressions):** Calculated measures for seat counts, alliance win percentages, and party rankings.
- **Power Query & Data Modeling:** Data cleaning, transformation, and relational schema design.
